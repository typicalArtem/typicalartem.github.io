# Настройка Workflow для мониторинга конкурентов в n8n

## Описание
Данный workflow автоматически проверяет новые публикации конкурентов в социальных сетях (Instagram, Facebook) и отправляет уведомления на email при обнаружении новых постов.

## Структура Google Таблицы

Создайте Google Таблицу со следующими колонками:

| A (username) | B (platform) | C (company_name) | D (last_check) |
|--------------|--------------|------------------|----------------|
| competitor1  | instagram    | Конкурент 1      | 2024-01-01T00:00:00.000Z |
| competitor2  | facebook     | Конкурент 2      | 2024-01-01T00:00:00.000Z |
| competitor3  | instagram    | Конкурент 3      | 2024-01-01T00:00:00.000Z |

### Описание колонок:
- **username**: Имя пользователя в социальной сети (без @)
- **platform**: Платформа (instagram/facebook)
- **company_name**: Название компании конкурента
- **last_check**: Дата последней проверки (обновляется автоматически)

## Настройка в n8n

### 1. Импорт workflow
1. Откройте n8n
2. Нажмите "Import from File"
3. Загрузите файл `competitor_monitor_workflow.json`

### 2. Настройка Google Sheets
1. В узле "Read Competitors List":
   - Замените `YOUR_GOOGLE_SHEET_ID` на ID вашей Google Таблицы
   - Настройте аутентификацию через Service Account

2. В узле "Update Check Timestamp":
   - Убедитесь, что указан тот же ID таблицы

### 3. Настройка Email
В узле "Send Email Notification":
- `fromEmail`: Укажите отправителя
- `toEmail`: Укажите получателя уведомлений

### 4. Настройка расписания
Workflow запускается ежедневно в 10:00 UTC. Для изменения времени:
1. Откройте узел "Daily Schedule"
2. Измените cron выражение `0 10 * * *`

## Поддерживаемые платформы

### Instagram
- Парсинг публичных профилей
- Извлечение текста, изображений и ссылок
- Определение даты публикации

### Facebook
- Парсинг публичных страниц
- Извлечение заголовков и описаний
- Поддержка Open Graph meta tags

## Принцип работы

1. **Ежедневный запуск**: Workflow активируется каждый день в 10:00
2. **Чтение списка**: Загружается список конкурентов из Google Таблицы
3. **Обработка**: Каждый конкурент обрабатывается по очереди
4. **Проверка платформы**: Определяется тип социальной сети
5. **Загрузка профиля**: Получается HTML страница профиля
6. **Парсинг**: Извлекаются новые публикации за последние 24 часа
7. **Фильтрация**: Отбираются только новые посты
8. **Уведомление**: Формируется и отправляется email с новыми публикациями
9. **Обновление**: Записывается время последней проверки

## Ограничения

1. **Публичные профили**: Работает только с открытыми аккаунтами
2. **Rate limiting**: Социальные сети могут ограничить частоту запросов
3. **Изменения интерфейса**: При обновлении соцсетей может потребоваться корректировка парсеров

## Безопасность

- Используется только веб-скрапинг публично доступной информации
- Не требует токенов доступа к социальным сетям
- Работает через стандартные HTTP запросы

## Расширение функциональности

Для добавления новых платформ:
1. Добавьте новое условие в узел "Check Platform Type"
2. Создайте новый узел для получения данных
3. Добавьте соответствующий парсер
4. Подключите к узлу "Merge Posts"

## Устранение неполадок

### Проблемы с парсингом
- Проверьте доступность профилей конкурентов
- Убедитесь, что профили публичные
- Проверьте настройки прокси, если используется

### Проблемы с email
- Проверьте настройки SMTP
- Убедитесь в корректности email адресов
- Проверьте права доступа для отправки писем

### Проблемы с Google Sheets
- Проверьте права доступа Service Account
- Убедитесь в корректности ID таблицы
- Проверьте формат данных в таблице
