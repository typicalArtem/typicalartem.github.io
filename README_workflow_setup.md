# 🚨 Workflow мониторинга конкурентов в Instagram

Этот workflow автоматически проверяет новые публикации конкурентов из Google Sheets и отправляет уведомления по email.

## 📋 Доступные версии

### 🔧 competitor_posts_workflow_simple.json (РЕКОМЕНДУЕМАЯ)
- ✅ **Простая в настройке** - не требует Graph API токенов
- ✅ **Работает без разрешений** - использует публичные данные Instagram
- ✅ **Надежная** - меньше точек отказа
- ⚠️ **Ограничение**: может периодически блокироваться Instagram при частых запросах

### 🔧 competitor_posts_workflow.json (УСТАРЕЛА)
- ❌ **Требует Graph API** - сложная настройка токенов
- ❌ **Проблемы с токенами** - частые ошибки OAuth
- ❌ **Ограниченный доступ** - работает только с Business аккаунтами

## 📋 Что делает workflow

1. **Читает список конкурентов** из Google Sheets
2. **Проверяет новые публикации** через Instagram Web API
3. **Фильтрует посты**, опубликованные за последние 24 часа
4. **Отправляет email-уведомления** с содержимым публикации
5. **Логирует результаты** в отдельную таблицу
6. **Обрабатывает ошибки** и отправляет уведомления администратору

## 🛠 Необходимые настройки

### 1. Выбор версии
**ИСПОЛЬЗУЙТЕ:** `competitor_posts_workflow_simple.json` - простая и надежная версия

### 2. Google Sheets структура

#### Основная таблица (лист 1):
| competitor_username | description |
|-------------------|-------------|
| username1         | Описание    |
| username2         | Описание    |

#### Лог таблица (лист 2):
| date | competitor | post_url | timestamp | status |
|------|------------|----------|-----------|--------|

### 3. Email настройки
- Настройте SMTP в n8n для отправки email
- Укажите свой email в ноде "Send Email Notification"

## 🔧 Настройка в n8n

### 1. Импорт workflow
```bash
# Скопируйте содержимое competitor_posts_workflow_simple.json
# Импортируйте в n8n через Settings → Import from file
```

### 2. Настройка нод

#### Google Sheets ноды:
- **"Read Competitors List"**: укажите ID вашей Google Sheets
- **"Log to Google Sheets"**: укажите тот же ID, лист 2

#### Email ноды:
- **"Send Email Notification"**: укажите ваш email для уведомлений  
- **"Send Error Notification"**: укажите admin email

### 3. Учетные данные
Настройте в n8n:
- **Google Service Account** для доступа к Sheets
- **SMTP credentials** для отправки email

## 🚀 Запуск

1. Нажмите "Test workflow" для ручного запуска
2. Workflow автоматически обработает всех конкурентов из таблицы
3. Никаких токенов вводить не нужно!

## 📧 Формат уведомлений

Email содержит:
- 👤 Информацию об аккаунте
- 📅 Дату публикации
- 📝 Текст поста
- 🖼️ Изображения (если есть)
- 🔗 Ссылку на публикацию
- 📊 Статистику (лайки, комментарии)

## ⚠️ Обработка ошибок

- Ошибки API отправляются администратору
- Некорректные username'ы фильтруются
- Логирование всех операций

## 🔄 Автоматизация

Для автоматического запуска замените "Manual Trigger" на:
- **Cron trigger** - для регулярного запуска
- **Webhook trigger** - для внешних вызовов

## 📊 Мониторинг

Все обработанные посты логируются во второй лист Google Sheets с информацией:
- Дата проверки
- Конкурент
- Ссылка на пост
- Статус обработки

## ⚠️ Важные замечания

### Простая версия (рекомендуемая):
- Не требует API токенов
- Может блокироваться при частом использовании
- Рекомендуется запускать не чаще 1 раза в час
- Работает только с публичными профилями

### Альтернативные решения:
- Используйте прокси-серверы для снижения блокировок
- Настройте задержки между запросами
- Рассмотрите использование сторонних API сервисов
