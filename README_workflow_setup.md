# 🚨 Workflow мониторинга конкурентов в Instagram

Этот workflow автоматически проверяет новые публикации конкурентов из Google Sheets и отправляет уведомления по email.

## 📋 Что делает workflow

1. **Читает список конкурентов** из Google Sheets
2. **Проверяет новые публикации** через Instagram Graph API
3. **Фильтрует посты**, опубликованные за последние 24 часа
4. **Отправляет email-уведомления** с содержимым публикации
5. **Логирует результаты** в отдельную таблицу
6. **Обрабатывает ошибки** и отправляет уведомления администратору

## 🛠 Необходимые настройки

### 1. Instagram Graph API
- Получите токен доступа к Instagram Graph API
- Токен должен иметь права: `instagram_basic`, `pages_read_engagement`

### 2. Google Sheets структура

#### Основная таблица (лист 1):
| competitor_username | description |
|-------------------|-------------|
| username1         | Описание    |
| username2         | Описание    |

#### Лог таблица (лист 2):
| date | competitor | post_url | timestamp | status |
|------|------------|----------|-----------|--------|

### 3. Email настройки
- Настройте SMTP в n8n для отправки email
- Укажите свой email в ноде "Send Email Notification"

## 🔧 Настройка в n8n

### 1. Импорт workflow
```bash
# Скопируйте содержимое competitor_posts_workflow.json
# Импортируйте в n8n через Settings → Import from file
```

### 2. Настройка нод

#### Google Sheets ноды:
- **"Read Competitors List"**: укажите ID вашей Google Sheets
- **"Log to Google Sheets"**: укажите тот же ID, лист 2

#### Email ноды:
- **"Send Email Notification"**: укажите ваш email для уведомлений
- **"Send Error Notification"**: укажите admin email

#### Set Graph API Token:
- В ноде "Set Graph API Token" введите ваш Instagram Graph API токен

### 3. Учетные данные
Настройте в n8n:
- **Google Service Account** для доступа к Sheets
- **SMTP credentials** для отправки email

## 🚀 Запуск

1. Нажмите "Test workflow" для ручного запуска
2. В ноде "Set Graph API Token" введите ваш токен
3. Workflow автоматически обработает всех конкурентов из таблицы

## 📧 Формат уведомлений

Email содержит:
- 👤 Информацию об аккаунте
- 📅 Дату публикации
- 📝 Текст поста
- 🖼️ Изображения (если есть)
- 🔗 Ссылку на публикацию
- 📊 Статистику (лайки, комментарии)

## ⚠️ Обработка ошибок

- Ошибки API отправляются администратору
- Некорректные username'ы фильтруются
- Логирование всех операций

## 🔄 Автоматизация

Для автоматического запуска замените "Manual Trigger" на:
- **Cron trigger** - для регулярного запуска
- **Webhook trigger** - для внешних вызовов

## 📊 Мониторинг

Все обработанные посты логируются во второй лист Google Sheets с информацией:
- Дата проверки
- Конкурент
- Ссылка на пост
- Статус обработки

## 🔑 Получение Instagram Graph API токена

1. Создайте Facebook App
2. Добавьте Instagram Basic Display product
3. Получите долгосрочный токен
4. Убедитесь, что токен имеет необходимые права
