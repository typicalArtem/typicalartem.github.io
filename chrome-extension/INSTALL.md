# Quick Installation Guide

## Install the Chrome Extension

### Step 1: Enable Developer Mode
1. Open Chrome and navigate to `chrome://extensions/`
2. Toggle on "Developer mode" in the top right corner

### Step 2: Load the Extension
1. Click "Load unpacked" button
2. Select the `chrome-extension` folder from this project
3. The extension will be loaded and appear in your extensions list

### Step 3: Pin the Extension
1. Click the puzzle piece icon (🧩) in the Chrome toolbar
2. Find "Social Media Downloader" in the list
3. Click the pin icon to keep it visible in the toolbar

### Step 4: Test the Extension
1. Navigate to YouTube, Instagram, or TikTok
2. Look for download buttons on videos/posts
3. Click the extension icon to access the popup interface

## Important Notes

- **This is a demo version**: The actual download functionality uses placeholder URLs
- **For production use**: You'll need to implement real media extraction logic
- **Legal compliance**: Only download content you have permission to download
- **Platform ToS**: Respect the terms of service of each platform

## Troubleshooting

- If the extension doesn't load, check that all files are in the `chrome-extension` folder
- If buttons don't appear, try refreshing the page
- Check the Chrome developer console for any error messages

Happy downloading! 🎉
